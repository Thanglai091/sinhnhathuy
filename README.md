# GIA HUY · CHAPITRE XIX (19+)

Trang web chúc mừng sinh nhật tuổi 19+ dành riêng cho **Gia Huy** (`25 · 11 · 2008` — Nhân Mã — Buôn Ma Thuột).

## Điểm nhấn kỹ thuật
- **Bìa mở đầu cửa đôi Haute-Joaillerie:** hiệu ứng tách cánh cửa sơn mài đen, viền Art Deco SVG và mặt đồng hồ horology xoay ngược chiều.
- **Hồ Sơ Bản Sắc (`#profile`):** bản đồ đồng mức Buôn Ma Thuột (536m), vòng chiêm tinh **Chòm Sao Nhân Mã (Sagittarius)** tương tác 7 ngôi sao và bảng khắc thông số Chronograph.
- **Đĩa than & Phổ âm thanh (`#soundstage`):** trình tổng hợp 3 bản nhạc bằng Web Audio API kết hợp `AnalyserNode` hiển thị phổ âm thanh 32 cột theo thời gian thực.
- **Bánh kem 3D WebGL (`#cake-ritual`):** dựng hoàn toàn bằng **Three.js** (`./vendor/three/three.module.js`), hỗ trợ xoay 360°, chạm trực tiếp lên nến 3D để thổi tắt, thổi bằng micro, pháo bông 3D và hiệu ứng Khui Champagne.
- **Hộp quà 3D & Thư Minh Thắng (`#gift-vault`, `#letter`):** mở nắp hộp quà 3D, mở phong bì gập 3D và thẻ kỷ niệm VIP xuất ảnh PNG `1200×700`.

## Chạy cục bộ

```bash
python -m http.server 8091
```
Mở trình duyệt tại `http://localhost:8091`.
